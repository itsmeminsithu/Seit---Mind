# စိတ် - Mind · အသုံးပြုသူလမ်းညွှန်

**Your space for peace, focus & better sleep.**

## Meditation စတင်ရန်

1. Browser မှာ စိတ် - Mind Website ကို ဖွင့်ပါ။ Android App သုံးသူများက App ကို ဖွင့်ပါ။ Browser Version မှာ App Install မလိုပါ။
2. Forest, Soft Piano, Ocean Tides, Rain စတဲ့ အသံ ၁၂ မျိုးထဲက တစ်မျိုးကို ရွေးပါ။
3. Meditation အချိန်ကို ၁၀၊ ၂၀၊ ၃၀ မိနစ် သို့မဟုတ် ကိုယ်ကြိုက်နှစ်သက်ရာ ၁–၁၈၀ မိနစ် သတ်မှတ်ပါ။
4. Start နှိပ်ပြီး အေးအေးဆေးဆေး အနားယူပါ။ Pause လုပ်ထားတဲ့ အချိန်ကို Meditation နာရီအဖြစ် မတွက်ပါ။

## Stars နှင့် Streak

- သတ်မှတ်ထားတဲ့ Meditation အချိန်ရဲ့ အနည်းဆုံး **၈၀%** ပြည့်မှ Session Completed ဖြစ်ပါမယ်။
- တကယ် နားထောင်ပြီးဆုံးတဲ့ **တစ်မိနစ် = တစ်ပွင့် Star** ရရှိပါတယ်။ တစ်နေ့ အများဆုံး **၆၀ Stars** ပါ။
- တစ်နေ့ စိတ်အေးအေးနဲ့ Meditation အောင်မြင်စွာ ပြုလုပ်တဲ့နေ့မှာ Streak တစ်ရက်တိုးပါတယ်။ တစ်နေ့တည်း ထပ်လုပ်လည်း Streak ထပ်မတိုးပါ။
- တစ်ရက် မလုပ်ဖြစ်လည်း ကိုယ့်ကိုယ်ကို အပြစ်တင်စရာမလိုပါ။ ပြန်စတင်နိုင်ပါတယ်။

## Quote နှင့် PNG Card

Session ပြီးတဲ့အခါ Mood ကို ရွေးပါ။ နေ့စဉ် Quote နှင့် သင်ရွေးတဲ့ Mood နဲ့ သက်ဆိုင်တဲ့ English/Myanmar Quote ကို ပြသပါမယ်။ PNG အတွက်

- **English / မြန်မာ / နှစ်ဘာသာ** ရွေးနိုင်ပါတယ်။
- **1080×1080 Square** သို့မဟုတ် **1080×1920 Story** ရွေးနိုင်ပါတယ်။
- **Forest / Sunset / Ocean / Cream** Theme ၄ မျိုး ရွေးနိုင်ပါတယ်။
- Name, Streak, Stars ကို Card မှာ ပြမလား ကိုယ်တိုင်ရွေးနိုင်ပါတယ်။ **မူလအခြေအနေမှာ အားလုံးပိတ်ထားပါတယ်။**
- Save PNG ကို ရွေးပြီး ဖုန်းထဲ သိမ်းနိုင်သလို Share နှိပ်ပြီး သူငယ်ချင်းများထံ ပို့နိုင်ပါတယ် (Browser ရဲ့ Support ပေါ်မူတည်ပါတယ်)။

## Profile နှင့် Reminder

User Profile Name နဲ့ Photo ကို စိတ်ကြိုက်ပြောင်းနိုင်ပါတယ်။ Android မှာ Daily Notification ချိန်နိုင်ပါတယ်။ Browser မှာတော့ Website ဖွင့်ထားချိန်သာ Reminder အလုပ်လုပ်နိုင်ပါတယ်။ Alarm နာရီအတိအကျအဖြစ် မယူဆသင့်ပါ။

User Data နဲ့ Stars/Streak တွေကို လက်ရှိ Device ထဲမှာပဲ သိမ်းထားပါတယ်။ Android နဲ့ Web အကြား Sync မဖြစ်သေးပါဘူး။ Browser Data ဖျက်မိရင် Browser Profile/Progress ပျောက်နိုင်ပါတယ်။
